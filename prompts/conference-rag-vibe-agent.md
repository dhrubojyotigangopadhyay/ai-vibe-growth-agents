# 🚀 Conference Talk Generator (RAG + Multi-Agent)

Generate high-quality conference talk proposals using AI.

---

## ⚡ Build

1. Open:
https://cursor.sh  
OR  
https://replit.com  

2. Create Python project  
3. Paste vibe prompt  
4. Run  

---

## 🧾 Requirements

Install Python:
https://www.python.org/downloads/

Install dependencies:

pip install -r requirements.txt

NEBIUS_API_BASE=https://api.tokenfactory.nebius.com/v1

## ▶️ Run

streamlit run talk_suggestions_app.py

---

## ⚡ First Run

- Enter topic idea  
- System runs research agents  
- Generates proposal  

---

## 💬 What It Does

- Crawls historical conference data  
- Uses embeddings for similarity search  
- Runs real-time research agents  
- Combines both contexts (RAG)  
- Generates unique proposal  

---

## 🔥 Why This Version

- Uses Nebius (NOT OpenAI)
- Uses Qwen 235B model
- Real RAG pipeline
- Multi-agent architecture
- Production-grade system
