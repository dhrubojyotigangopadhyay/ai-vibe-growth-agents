# 🎧 Customer Support Voice Agent (Vibe Version)

A simple AI-powered voice agent that:
- Listens to user speech
- Converts it to text
- Generates a support response
- Speaks the response back

---

## ⚡ Build

1. Open:
   https://cursor.sh  
   OR  
   https://replit.com  

2. Paste the Vibe Coding Prompt  
3. Run the project

---

## 🧾 Requirements

- Python 3.9+
  https://www.python.org/downloads/

- Install dependencies:

pip install -r requirements.txt

---

## 🔑 API KEY

Provider: OpenAI

Get your API key:
https://platform.openai.com/signup

Set environment variable:

OPENAI_API_KEY=your_key_here

OR paste it when prompted on first run

---

## ▶️ Run

python main.py

---

## ⚡ First Run

- App asks for API key (if not set)
- Records your voice
- Converts speech → text
- Sends to AI
- Speaks response back

---

## 💬 What It Does

- Records microphone input
- Uses Whisper for speech-to-text
- Uses GPT-4o-mini for response generation
- Uses TTS to generate voice reply

---

## 🔥 Why This Version

- Same OpenAI API
- Same models (Whisper + GPT-4o-mini + TTS)
- Same functionality
- Simplified setup
- Beginner-friendly
