# 📱 Social Media AI Agent (Memory-Based)

AI agent that learns your writing style and generates social media content.

---

## ⚡ Build

1. Open:
https://cursor.sh  
OR  
https://replit.com  

2. Create Python project  

3. Paste the vibe prompt  

4. Run  

---

## 🧾 Requirements

Install Python:  
https://www.python.org/downloads/  

Install dependencies:

pip install -r requirements.txt  

---

## 🔑 API KEY

This app uses Nebius.

Get API key:  
https://nebius.com/token-factory  

Set in .env:

NEBIUS_API_KEY=your_key_here  

---

## ▶️ Run

python main.py  

---

## ⚡ First Run

- App will ask API key if missing  
- Start chatting with agent  

---

## 💬 What It Does

- Learns your writing style  
- Stores past posts in memory  
- Generates tweets, LinkedIn posts, etc.  
- Maintains consistent tone  

---

## 🔥 Why This Version

- Uses Nebius (NOT OpenAI)  
- Uses DeepSeek-V3 model  
- Memory-based personalization  
- Persistent style learning  
- Real agent architecture
